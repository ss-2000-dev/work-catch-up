# Jiraのキーボードショートカット

対象読者:マウス操作でチケットを1件ずつ開いて編集しており、キーボードショートカットをまだ使っていない人。慣れれば「チケットを開く→コメントする→閉じる→次を開く」のようなルーティン作業がかなり速くなる。

Jira内であれば`?`キーを押すと、現在の画面で使えるショートカット一覧がその場で表示される。全部覚える必要はなく、まず「移動系」と「作成系」だけ覚えれば十分。

---

## 1. まず覚える最重要3つ

| キー | 動作 |
|---|---|
| `c` | 新規チケット作成ダイアログを開く |
| `/` | 検索ボックスにフォーカス(クイックサーチ) |
| `?` | ショートカット一覧を表示 |

## 2. 画面移動

| キー | 動作 |
|---|---|
| `g` → `g` | 「Go to」プロンプトを開き、プロジェクト/ボード名を入力してジャンプ |
| `g` → `i` | 自分に割り当てられたチケット一覧へ移動 |
| `g` → `b` | ボード一覧/直前のボードへ移動 |

## 3. チケット詳細画面での操作

| キー | 動作 |
|---|---|
| `a` | 担当者(Assignee)をアサイン |
| `m` | コメント入力欄にフォーカス |
| `i` | ウォッチャーになる/やめる(Watch/Unwatch) |
| `l` | ラベルを編集 |
| `e` | チケットを編集(Editモードを開く) |
| `.` | 「その他の操作」コマンドパレット的なメニューを開く(ワークフロー遷移やその他アクションを検索して実行できる) |
| `Esc` | 開いているダイアログ/フォームを閉じる |

## 4. 課題一覧・検索結果での操作

| キー | 動作 |
|---|---|
| `j` / `k` | 一覧内でチケットを下/上に移動(選択) |
| `o` または `Enter` | 選択中のチケットを開く |
| `[` / `]` | チケット詳細画面で前後のチケットに移動 |

## 5. コメント入力時

| キー | 動作 |
|---|---|
| `Cmd/Ctrl + Enter` | コメントを送信 |
| `@` | メンション(担当者やウォッチャーへの通知)を挿入 |

## 6. 実務での使い方のコツ

- 朝会前のチケット確認ルーティン(検索→1件ずつコメント/ステータス確認)は `/` → JQL入力 → `j/k`で流し見 → 気になるものだけ`Enter`で開く、が最速
- 一括でコメントやステータス変更が必要な場合はショートカットより[`jira-features.md`](./jira-features.md)の「一括変更」機能を使う方が速い(ショートカットは1件ずつの操作向け)

ショートカットはブラウザ拡張機能やブラウザ側の既存ショートカット(例:`Cmd+F`)と衝突することがあるため、効かない場合はJira側の設定でショートカットが有効化されているか確認する(プロフィールアイコン→「キーボードショートカット」設定)。
