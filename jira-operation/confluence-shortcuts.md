# Confluenceのキーボードショートカット

対象読者:議事録・仕様書・スプリントレビュー資料などをConfluenceで作成する機会があり、編集操作を速くしたい人。JiraのショートカットとはUIが異なるため別ドキュメントとして分けている。

Confluence上でも`?`キーでショートカット一覧を表示できる(エディタ内・エディタ外どちらでも)。

---

## 1. まず覚える最重要3つ

| キー | 動作 |
|---|---|
| `c` | 新規ページ作成 |
| `/` | ページ内でスラッシュコマンドメニューを開く(見出し・表・コードブロックなどの挿入) |
| `?` | ショートカット一覧を表示 |

## 2. 画面移動・検索

| キー | 動作 |
|---|---|
| `g` → `g` | 「Go to」でスペース/ページへジャンプ |
| `s` | 検索ボックスにフォーカス |

## 3. エディタ内での書式操作

| キー | 動作 |
|---|---|
| `Cmd/Ctrl + B` | 太字 |
| `Cmd/Ctrl + I` | イタリック |
| `Cmd/Ctrl + Shift + 7` | 番号付きリスト |
| `Cmd/Ctrl + Shift + 8` | 箇条書きリスト |
| `Cmd/Ctrl + K` | リンク挿入 |
| `Cmd/Ctrl + Shift + K` | コードブロック挿入 |
| `Cmd/Ctrl + Shift + I` | 画像/ファイル添付を挿入 |

## 4. スラッシュコマンド(`/`)でよく使うもの

`/`を入力すると出てくるメニューから、マウスに頼らず要素を挿入できる。特に議事録・仕様書作成で使う頻度が高いもの:

| 入力例 | 挿入されるもの |
|---|---|
| `/table` | 表 |
| `/status` | ステータスラベル(色付きバッジ、例:進行中/完了) |
| `/task` | タスクリスト(チェックボックス、担当者アサイン可) |
| `/info` `/warning` `/note` | 色付きの注意書きパネル |
| `/toc` | 目次(見出しから自動生成) |
| `/jira` | Jiraチケットへのリンク・埋め込み(ライブフィルターも可) |

## 5. コメント・共同編集

| キー | 動作 |
|---|---|
| `@` | メンションを挿入(通知が飛ぶ) |
| 選択テキスト → コメントアイコン | 該当箇所にインラインコメントを追加 |
| `Cmd/Ctrl + Enter` | コメント/公開を確定 |

## 6. 実務での使い方のコツ

- 議事録テンプレートは`/`メニューの「Meeting notes」テンプレートから始めると、決定事項・アクションアイテムの見出しが最初から入っている
- 仕様書内でJiraチケットの状態をリアルタイムに見せたい場合は`/jira`でチケットを埋め込むと、ステータス変更が自動で反映され手動更新が不要になる
- ページのステータス管理(ドラフト/レビュー中/承認済み)は`/status`ラベルをページ冒頭に置く運用にしておくと、関係者がひと目で確認できる

Jiraチケットの埋め込み(`/jira`)を使うには、埋め込み先のJiraプロジェクトへの**「参照(Browse Projects)」**権限がConfluence側のアカウントにも必要(JiraとConfluenceが同じAtlassianサイトに接続されている前提)。
