# GA(Googleアナリティクス)関連ドキュメント

`front-end/`のサンプルプロジェクトがGA4を前提としたMPA構成になっている背景も含め、GA4について理解・実装するためのドキュメントをまとめています。

## 読む順番

1. **[GA4の基礎知識.md](GA4の基礎知識.md)**
   GA4とは何か / 何が計測できて何ができないか / POと会話するための用語集。
   非エンジニアでも読める内容です。まずこちらから。

2. **[GA4の実装ガイド.md](GA4の実装ガイド.md)**
   着手前の確認事項 / 実際に書くコード / 開発時の注意点 / 実装チェックリスト。
   コード例は`front-end/`のサンプルプロジェクトにそのまま組み込める形で書いています。

## このドキュメントを読み終わった状態の目安

- [ ] GA4とUAの違いを説明できる(「すべてがイベント」というデータモデルの転換)
- [ ] 「それはGAでは測れません」と根拠を持って言える
- [ ] 「後から遡って計測することはできない」ため、計測設計を先に行う必要があると説明できる
- [ ] 計測タグの設置と、カスタムイベントの実装が自分で書ける
- [ ] POが言う「コンバージョン」「PV」「イベント追加して」が、実装上何を意味するか翻訳できる
